## 4. 本轮发现与修复

|缺陷|现象 / 根因|修复|证据|
|---|---|---|---|
|DEF-01|历史种子给12人安排同一10人班，初始化被业务校验拒绝|历史公共班缩至10人；统一数学先修及调整秋季新生课程|seed_demo被每个集成fixture调用|
|DEF-02|后台线程用_stop字段遮蔽Thread内部方法，join可能报错|改为_stop_event|test_backoff_and_worker|
|DEF-03|选课提交后重新读目录，可能业务成功但返回失败|同事务、同快照组装返回结果|注册回归及代码检查|
|DEF-04|关闭已提交后即时投递异常可能误报关闭失败|保留业务成功与发件箱，记录投递异常|test_postcommit_delivery_error_keeps_success|
|DEF-05|教授首页依赖目录失败后重定向到自身|GET业务错误直接返回故障页面|test_professor_catalog_outage_does_not_redirect_loop|
|DEF-06|跨学期切换时可能使用旧目录快照写入新学期|写事务内比对学期code|代码检查；专门竞态注入仍待补充|

修复后全套51项通过。没有声称所有未覆盖分支都已验证。
